# 🌟 ABP Portfolio

A stunning, modern portfolio website built with React, featuring smooth animations, dark mode support, and an elegant design inspired by premium web experiences.

![TailwindCSS](https://img.shields.io/badge/TailwindCSS-4.1-38B2AC?style=for-the-badge&logo=tailwind-css&logoColor=white)
![Framer Motion](https://img.shields.io/badge/Framer_Motion-12.23-E831E6?style=for-the-badge&logo=framer&logoColor=white)

## ✨ Features

- 🎨 **Modern Design** - Clean, minimalist interface with premium aesthetics
- 🌓 **Dark Mode** - Full dark mode support with smooth transitions (defaults to dark mode)
- 🎭 **Smooth Animations** - Powered by Framer Motion and GSAP
- 🎯 **Custom Cursor** - Interactive custom cursor on desktop
- 📱 **Fully Responsive** - Optimized for all devices
- ⚡ **Fast Performance** - Built with Vite for lightning-fast load times
- 🎪 **3D Elements** - Using React Three Fiber for immersive experiences
- 🧭 **Smooth Navigation** - React Router with seamless page transitions
- 🎬 **Preloader Animation** - Elegant loading experience

## 🚀 Tech Stack

### Core
- **React 19** - Latest React features
- **Vite** - Next-generation frontend tooling
- **React Router DOM** - Client-side routing

### Styling
- **TailwindCSS 4** - Utility-first CSS framework
- **Custom CSS** - SF Pro Display & General Sans fonts

### Animation
- **Framer Motion** - Production-ready motion library
- **GSAP** - Professional-grade animations

### 3D Graphics
- **React Three Fiber** - React renderer for Three.js
- **React Three Drei** - Useful helpers for React Three Fiber
- **Three.js** - JavaScript 3D library

## 📦 Installation

```bash
# Clone the repository
git clone <your-repo-url>

# Navigate to project directory
cd abp-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

## 🛠️ Available Scripts

```bash
# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview

# Run ESLint
npm run lint
```
